About ghosecorp-auth

ghosecorp-auth is a scalable, microservices-based authentication system built to secure modern cloud ecosystems. It provides a robust framework for managing user identities, session persistence, and third-party integrations.

OAuth 2.0 / PKCE Multi-Factor Auth PostgreSQL

Security Features

Flexible Auth

Supports Email/Password, Social OAuth (Google, Microsoft), and custom provider integrations.

Core API

The heart of the system, handling session management, credential validation, and token issuance with high-performance throughput.

Microservices Ready

Designed with a modular architecture: Core API, Mailer Service, and automated DB setup scripts.

OAuth Provider

Acts as an OAuth 2.0 provider, allowing third-party applications to integrate securely with your ecosystem.

Architecture Components

  • auth-api: Core logic and session handling
  • auth-mailer: Automated email notifications and OTPs
  • setup: Automated database initialization
